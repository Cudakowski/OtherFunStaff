# CudakowyTemplate

## Configure at start
1. **Directory name is your project name.**
2. When first building select compilator. Not default option. The one you have installed.
3. In .vscode/launch.json and CMakeLists.txt change segments with comments to your liking

## How to use
f7 for building with cmake

Make new classes with Class.sh (even on windows with bash terminal in vsc)

Build is debug by default. You can change it to Release in CMakeLists.txt

Your executable is in build folder. It has project name. Run it with f5/ctrl+f5 or in console.

For debugging it's already selected specyfied configuration. The "Configured debug" one.
